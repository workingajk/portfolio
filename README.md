# Portfolio Website

A personal portfolio website implemented with HTML and CSS. It includes a main page and supporting visual resources.

## Tech Stack
- HTML5
- CSS3

## Run Locally
Open `index.html` in a web browser. No build step is required.

## Project Structure
- `index.html` — portfolio content
- `style.css` — page styling
- `img/` and `res/` — images and supporting resources
